# Finance Analytics Dashboard

Веб-приложение для мониторинга эффективности проектов с аналитикой финансовых данных.

## 🚀 Функциональность

### 📊 4 основных отчета:

1. **Отчет 1: Эффективность выбранных проектов**
   - Иерархическое представление данных (Уровень 1 → Уровень 2 → Уровень 4)
   - Выбор проектов с группировкой (DCA, DP, Прочие)
   - Метрики ROI и маржинальности
   - ТОП-10 расходов для убыточных проектов

2. **Отчет 2: Сводная таблица всех проектов**
   - Ключевые показатели всех проектов
   - Графики: Топ-5 по ROI, распределение по группам, динамика маржинальности
   - Фильтрация и поиск

3. **Отчет 3: Анализ статей расходов/доходов**
   - Солнечная диаграмма (Sunburst) с иерархией статей
   - Топ-5 доходных и расходных статей
   - Детальный анализ каждой статьи

4. **Отчет 4: Анализ ФОТ и сотрудников**
   - Распределение ФОТ по проектам
   - Анализ эффективности затрат на персонал
   - Рекомендации по оптимизации

## 🛠 Технологии

**Backend:**
- Python 3.11
- Flask (веб-фреймворк)
- SQLAlchemy (ORM)
- PostgreSQL (база данных)
- JWT (аутентификация)

**Frontend:**
- HTML5, CSS3, JavaScript (ES6)
- Chart.js (графики)
- DataTables (таблицы)
- Flatpickr (выбор дат)
- Apple-inspired дизайн

**Инфраструктура:**
- Render (хостинг)
- Git (версионирование)
- Gunicorn (WSGI сервер)
